# Lecture Tracker

A small web app for keeping track of a semester's lectures.

- Add a course with its lecture days and the first and last day of teaching; the lecture list is built from the dates.
- Strike out cancelled lectures, give each lecture a title, and tick it every time you study it.
- Works on phone and iPad, can be added to the home screen, and opens without internet after the first visit.

Data is saved on the device you use (in the browser), not on a server.

Plain HTML, CSS and JavaScript in one file (`index.html`), hosted on GitHub Pages.
